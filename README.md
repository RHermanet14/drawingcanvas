# drawingcanvas README

A way to better express how your code works natively in Visual Studio.

## Features

When activated, the extension will take a reference of the last file opened in Visual Studio Code and format it as a webview with a canvas on top of the file, allowing you to draw on top of and visually explain the flow of the code.
